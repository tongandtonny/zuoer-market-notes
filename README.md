# 左耳的空间：A股市场观察与研究方法笔记

一个免费、无需注册的中文网页，把公开行情、财经快讯和研究方法笔记集中查看。

**[打开网站](https://a-stock-agent.pages.dev/) · [第一次使用](https://a-stock-agent.pages.dev/start) · [研究笔记](https://a-stock-agent.pages.dev/research)**

## 适合谁

希望减少来回切换网页、愿意核对数据来源和统计范围的A股学习者。可以先读一篇笔记，再查看行情，不需要注册或联系客服。

## 当前可以做什么

- 查看固定20只观察股票的来源行情。它们不是全市场榜单或推荐名单。
- 查看部分龙虎榜公开记录，保留交易日期、上榜原因和金额单位。
- 阅读财经快讯并打开来源原文。
- 搜索研究方法笔记，将文章收藏在当前浏览器。
- 在手机或电脑上阅读，切换浅色和深色主题。

行情约每5分钟重新读取，财经快讯约每2分钟读取；实际时效取决于来源，页面显示来源时点和获取状态。这不是秒级行情推送。研究笔记由编辑维护，不会随股价自动生成。
